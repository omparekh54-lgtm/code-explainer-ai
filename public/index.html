A tutor beside your code

Choose your level, paste up to 4,000 characters (80 lines), and request an explanation. Live AI sends the snippet to Gemini through a server function. The API key never reaches your browser.

Demo mode supports five included examples with curated explanations. It uses no AI quota. Demo content is the same across learning levels; live explanations adapt to your selection.

The app never executes code, stores code in a database, or saves it in your browser. Recent live responses may be held in server memory for up to 10 minutes to avoid duplicate AI calls. Refreshing clears your workspace.

Live requests have a small rate limit. AI explanations may contain mistakes, so verify the result before relying on it.
